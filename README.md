# Task Queue Simulator

## О проекте

Симулятор очереди задач с приоритетами, разработанный на языке Rust с использованием библиотеки `egui` для графического интерфейса.

## Возможности

- **Приоритеты задач**: Critical → High → Medium → Low
- **Три этапа выполнения задачи**: подготовка, основная работа, завершение
- **Приостановка задач** с возможностью последующего возобновления
- **Случайная генерация задач** с настраиваемыми параметрами
- **Визуализация прогресса** выполнения задач
- **История выполненных задач**

## Управление

| Действие | Описание |
|----------|----------|
| ▶ Старт симуляции | Запускает выполнение задач |
| ⏸ Пауза симуляции | Останавливает весь процесс |
| ⏸ Приостановить задачу | Приостанавливает текущую активную задачу |
| ➕ Новая задача | Открывает диалог создания задачи |
| 🎲 Случайная задача | Мгновенно создаёт задачу со случайными параметрами |

## Установка и запуск

### Требования
- Rust (последняя стабильная версия)
- Cargo

### Запуск

```bash
cargo run
```

## Технологии
Rust — основной язык программирования
egui — Immediate Mode GUI библиотека
rand — генерация случайных значений

## Структура проекта
```bash
src/
├── main.rs    # Основной код приложения
Cargo.toml     # Зависимости и конфигурация проекта
```
